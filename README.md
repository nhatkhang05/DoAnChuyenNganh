# Đồ án chuyên ngành – Hệ thống đặt lịch và quản lý quy trình khám bệnh

Thư mục này chứa toàn bộ code của đề tài.

- `frontend/` : giao diện web (React + TypeScript + Tailwind CSS + Vite). Đã xong phần giao diện, chạy được.
- `backend/`  : NestJS (TypeScript). Chưa làm, sẽ tạo thư mục này sau.

Cách chạy frontend xem trong `frontend/README.md`.
